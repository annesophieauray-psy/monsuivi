Entre-Séances : fichiers à déposer tels quels à la racine du dépôt GitHub.
- index.html : application patient (lien à donner aux patients)
- praticienne.html : votre espace (vos données restent dans votre navigateur, chiffrées)
- config.js : à compléter avec l'adresse de votre relais Google (voir Réglages > Guide dans votre espace)
- manifest.json, manifest-pro.json, sw.js, icônes : installation sur l'écran d'accueil et usage hors connexion
Aucune donnée patient n'est stockée sur GitHub.
